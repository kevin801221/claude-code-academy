01

CLAUDE.md 是什麼？

一份寫給 Claude 的 Markdown 指令檔，讓專案慣例在每次 session 都「被記得」。

結構良好的 CLAUDE.md，是改善 Claude Code 在你專案上表現最有效的單一手段。

Claude Code 會把 CLAUDE.md 讀進脈絡（context），你的專案慣例、程式碼標準、注意事項就不用每次重講一遍 —— 這就是持久脈絡。

但當檔案一多（例如 monorepo），哪些 CLAUDE.md 會在什麼時候被載入，就決定了 Claude 看到什麼、脈絡有多擠。這正是接下來要學的重點。

02

兩種載入機制

Claude Code 用兩種不同機制載入 CLAUDE.md：一個往上走、一個往下等。看動畫理解差別。

祖先載入 往目錄樹「上」走

啟動時，從當前工作目錄往上走到檔案系統根目錄，沿途找到的每一個 CLAUDE.md 都立即載入。

/（沒有 CLAUDE.md）
/mymonorepoCLAUDE.md
/mymonorepo/frontendcwdCLAUDE.md

後代載入 往目錄樹「下」等

子目錄的 CLAUDE.md 不會在啟動時載入，要等 Claude 在 session 中讀取那些子目錄的檔案時才納入 —— 延遲載入（lazy loading）。

/mymonorepocwdCLAUDE.md
frontend/CLAUDE.md
src/App.tsx
backend/CLAUDE.md

03

Monorepo 載入實驗室

選一個目錄啟動 Claude，看它往上掃描；再點「讀取」模擬 Claude 在 session 中讀檔，觀察哪些 CLAUDE.md 進入脈絡、哪些永遠不會。

① 在哪裡啟動 claude？
檔案系統 ③ 啟動後，點檔案的「讀取」
脈絡視窗 Context 大小僅為示意
事件紀錄
啟動時載入 延遲載入 全域 不載入（兄弟分支）

情境題：先猜，再揭曉

同一個 monorepo，從不同目錄啟動，啟動時載入的 CLAUDE.md 就不一樣。每一列先猜「會／不會」載入。

重點整理
四張卡片，點一下翻面。

    

    

      

        

          
01
祖先一律在啟動時載入
點擊翻面 ↻

          
01 · 祖先載入
Claude 往目錄樹上走，載入找到的所有 CLAUDE.md。這確保你永遠能取得根層級、整個 repo 適用的指令。

        

      

      

        

          
02
後代延遲載入
點擊翻面 ↻

          
02 · 延遲載入
子目錄的 CLAUDE.md 只有在你操作該子目錄的檔案時才載入，避免不相關的脈絡把 session 撐爆。

        

      

      

        

          
03
兄弟目錄預設不載入
點擊翻面 ↻

          
03 · 兄弟目錄
如果你在 frontend/ 工作，backend/CLAUDE.md 或 api/CLAUDE.md 預設不會進入脈絡。例外：用 --add-dir 加入該目錄，並設定 CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1。

        

      

      

        

          
04
全域 CLAUDE.md
點擊翻面 ↻

          
04 · 全域
在家目錄放 ~/.claude/CLAUDE.md，它會套用到所有 Claude Code session，不分專案。

        

      

    


    

      
這個設計為什麼適合 Monorepo？

      

        

          
        

        
    
          
  • ↓
    共用指令會向下傳播根層級 CLAUDE.md 放整個 repo 適用的慣例、程式碼標準與共通模式。
    • 
          
  • ║
    元件專屬指令保持隔離前端開發者不需要後端專屬指令來塞爆脈絡，反之亦然。
    • 
          
  • KB
    脈絡經過最佳化延遲載入後代 CLAUDE.md，避免在啟動時載入可能高達數百 KB 的無關指令。

＋
官方文件補充：還有這些記憶機制
上面的內容整理自社群文章。以下是 Claude Code 官方文件（2026 年 11 月）裡，學記憶時值得一起知道的幾件事。

    
    
      
  • 自動記憶預設開啟：Claude 會自己記下建置指令、除錯心得，每次對話開始載入 MEMORY.md 的前 200 行或 25KB；用 /memory 開關。
    • 
      
  • @ 匯入：CLAUDE.md 可以寫 @path/to/file 匯入其他檔案（最多 4 層），已有 AGENTS.md 就寫 @AGENTS.md。匯入的內容在啟動時就會載入，不會省脈絡。
    • 
      
  • 規則檔：把指令拆到 .claude/rules/*.md；frontmatter 設了 paths 的規則，只在讀到相符檔案時才載入。
    • 
      
  • 確認載入了什麼：用 /memory 或 /context 查看已載入的 CLAUDE.md 與規則檔；沒列出來的，Claude 就看不到。
    • 
      
  • CLAUDE.local.md 跟 CLAUDE.md 一樣，啟動時會沿著上層目錄載入；用 /init 選個人選項，會自動把它加進 .gitignore。
    • 
      
  • 壓縮之後：執行 /compact 後，子目錄的 CLAUDE.md 要等 Claude 再讀到那個資料夾的檔案才會重新載入。
    •
