建議學習路徑

三個模組彼此相連：先懂單一 session 的記憶，再看多個 session 怎麼協作，最後讓代理長時間自己跑。

01
基礎Claude Memory

每個 Claude Code session 都從 CLAUDE.md 取得持久脈絡 —— 搞懂它在何時、從哪裡被載入。

02
擴展Agent Teams

每個隊友都是獨立 session，會各自自動載入 CLAUDE.md、MCP server 與 skills，再透過共享任務清單協作。

03
持續/goal

設定一個條件，讓代理跨回合持續工作，直到 Haiku 評估條件成立為止。
